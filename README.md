# Air Quality Forecasting System Based on IoT and Machine Learning

## About the Project

This project aims to develop a system that forecasts air quality using historical environmental data, Internet of Things (IoT) concepts, and machine learning.

The system is intended to help users understand current air quality conditions and view predicted changes. The project will focus on data processing, machine learning, a backend API, and a simple web interface.

The project is being developed as a bachelor's diploma project at Astana IT University.

## Project Objectives

- Research existing air quality monitoring and forecasting systems.
- Select and prepare a suitable dataset for air quality forecasting.
- Develop and evaluate a machine learning model.
- Design a backend API for processing data and providing forecasts.
- Create a simple web interface for presenting air quality information.
- Test the system and evaluate the forecasting results.

## Project Structure
- `docs/` — project documentation organized into seven topic-based directories:
  - `architecture/` — system architecture and diagrams documentation.
  - `evaluation/` — verification, testing, and model evaluation plan.
  - `literature-review/` — literature review and research findings.
  - `project-proposal/` — project proposal, problem statement, objectives, and scope.
  - `requirements/` — functional and non-functional requirements with acceptance criteria.
  - `system-comparison/` — comparison of existing air-quality monitoring and forecasting systems.
  - `technology-comparison/` — comparison of alternative technologies and technical decisions.
- `diagrams/source/` — editable source files for architecture diagrams.
- `diagrams/exports/` — exported diagrams for reports and presentations.
- `prototype/` — interactive HTML dashboard prototype and related materials.
- `src/` — application source code, organized into the following components:
  - `src/frontend/` — user interface and dashboard.
  - `src/backend/` — backend logic, API endpoints, and interaction between system components.
  - `src/ml/` — data preprocessing, model training, evaluation, and forecasting.
- `tests/` — automated and manual test materials.
- `requirements.txt` — Python dependencies.
- `.gitignore` — files and directories excluded from version control.

The `frontend`, `backend`, and `ml` directories define the planned application structure. Their implementation will be added progressively as the project develops.

## Project Scope

The planned system will use historical air quality data to develop and evaluate a forecasting model. The final functionality, dataset, and forecasting horizon will be defined during the requirements and design stages.

IoT integration will be considered as part of the system design. The exact implementation will depend on the project requirements and available data.
